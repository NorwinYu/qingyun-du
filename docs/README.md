## 文档约定

- 玩法文档只写**已实现**内容，未实现的能力统一放在“当前版本范围”。
- 数值以 `src/data.js` 为准；调整数值时同步更新玩法文档。
- 新增玩法时，至少更新玩法指南对应章节与更新日志。
